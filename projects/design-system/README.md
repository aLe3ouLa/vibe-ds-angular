# @alexandra/design-system

Accessible Angular components and design tokens for product applications.

## Installation

```bash
npm install @alexandra/design-system
```

## Usage

```ts
import { Button } from '@alexandra/design-system';
```

```html
<ds-button variant="primary">Play</ds-button>
```

## Available components

- `ds-button`

## Documentation

See the repository component documentation and Storybook stories for supported states and accessibility behavior.

## Development

Build the library with:

```bash
npm run build
```
